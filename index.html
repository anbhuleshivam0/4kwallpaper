📚 Setup Guide

Follow these steps to set up your own 4K Wallpapers website with Supabase:

Step 1: Create Supabase Project

  1. Go to supabase.com
  2. Sign up and create a new project
  3. Choose your region and wait for the project to initialize

Step 2: Create Database Table

  1. Open your Supabase project dashboard
  2. Click SQL Editor in the left menu
  3. Click New Query
  4. Copy & paste the SQL from setup.sql file
  5. Click Run to execute

Step 3: Get Your Credentials

  1. In Supabase dashboard, click Settings → API
  2. Copy your Project URL
  3. Copy your Anon Key (public key)

Step 4: Add Wallpapers

  1. Go to Supabase Table Editor
  2. Open the wallpapers table
  3. Click Insert Row
  4. Fill in: title, image_url, category, description
  5. Image URLs work from: Unsplash, Pexels, Pinterest, Pixabay

Step 5: Deploy to GitHub Pages

  1. Push all files to GitHub repository
  2. Go to repo Settings → Pages
  3. Select main branch as source
  4. Your site is live! 🚀

💡 Tip: For best results, use high-quality image URLs (3840x2160 or higher). You can find great wallpapers on Unsplash, Pexels, or Pinterest!
